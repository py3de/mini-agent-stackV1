# Security and hosting

## Data residency
All customer data is hosted in the EU, in data centres in Frankfurt (Germany) and Dublin (Ireland).
No customer data leaves the EU. LLM calls for EU customers use EU-hosted model endpoints only.

## GDPR and data processing agreement
We sign a data processing agreement (DPA, Auftragsverarbeitungsvertrag) with every customer before
go-live. The standard DPA can be sent on request and is usually signed within one week.

## Written confirmation of EU hosting
Customers who need written confirmation of EU hosting receive a signed hosting statement from our
security team, normally within two working days of the request.

## Access control
Access to production systems requires SSO and multi-factor authentication. Access is reviewed quarterly.
